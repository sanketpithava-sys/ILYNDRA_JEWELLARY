# Ilyndra Monorepo

Enterprise monorepo structure for a luxury jewelry eCommerce platform.

## Workspace
- apps/web: Next.js storefront (no pages created yet)
- apps/admin: Next.js admin panel (no pages created yet)
- apps/api: NestJS backend (structure only)
- packages/*: shared libraries and configs
- infra/*: deployment and infrastructure scaffolding
- env/*: environment variable templates

No UI or pages are included yet.
